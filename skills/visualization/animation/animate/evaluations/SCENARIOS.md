# Animate evaluation specifications

These are test specifications, not executed platform test results.

| Scenario | Expected behavior |
|---|---|
| @animate a surveying procedure | Activate animate and delegate; choose suitable renderer, all phases, accurate geometry and annotations. |
| /animate a 3D building construction sequence | Activate animate, delegate and 3d; shared geometry/timeline contracts and all three applicable quality gates. |
| @ANIMATE | Explicit case-insensitive invocation; ask only for missing subject if no context. |
| What is animation? | Informational answer without unsolicited artifact creation. |
| @ask @animate an ambiguous teaching app | Resolve Ask's intent confirmation before implementation workers or file mutations. |
| Native worker tools absent when Delegate is required or selected | Delegate sequential fallback; no invented independent auditor. |
| Conditionally required Delegate content inaccessible for multi-phase or 3D animation | Disclose blocker; do not claim compliant execution. |
| SVG explanation of hydrostatic pressure | Choose suitable 2D renderer; accurate equations and synchronized labels; no unnecessary 3d. |
| Seismic response at 0.5x, 1x and 2x | Same physical state at the same simulation time; no changed solver step due to playback speed. |
| Seek backward after fracture or component installation | Reconstruct correct topology and pre-event state; no residual mutation. |
| Skip phases, replay, loop and frame step | Deterministic boundary state and accurate controls; no accumulated timing error. |
| Optional event hold and seek past it | Hold triggers only according to playback policy; seek does not trap user or replay side effects. |
| Change invalidating parameter during playback | Validate, pause/recompute, cancel stale result and atomically update coherent revision. |
| Manual camera while phase changes | Preserve user override until explicit resume; no camera fighting. |
| Fullscreen unsupported or denied | Provide labeled viewport-maximized fallback with reachable controls and exit. |
| Touch or keyboard after controls auto-hide | Controls reveal; focus remains usable; no hover dependency. |
| Reduced-motion setting | No forced autoplay or decorative camera movement; necessary motion remains manually controllable. |
| Default launch | Meaningful first frame, paused, silent; controls visible while paused. |
| Request GIF/video export without available codec | No fake export; disclose limit and deliver supported output. |
| Audit 97/100 but wrong governing equation or broken seeking | FAIL regardless of score; fix and re-audit. |
| Browser unavailable | Report static evidence and missing runtime proof; no fabricated playback certification. |
| Animate a simple 2-state CSS/SVG toggle | Select animate without requiring delegate; apply the Animate 95/100 gate. |
