# Delegate evaluation scenarios

These are evaluation specifications, not executed test results.

| Scenario | Expected behavior |
|---|---|
| Explicit delegation of a multi-section technical report | Activate Delegate; independent worker contracts, isolated scopes, assembly and audit. |
| Single arithmetic calculation without delegation | Do not activate Delegate. |
| Tightly coupled root-cause debugging | Choose Builder → Adversarial Challenger → Fixer; avoid artificial splitting. |
| Host lacks native workers | Sequential role passes; explicitly non-independent audit; no invented agents. |
| One worker fails | Re-task only that workstream; preserve verified outputs. |
| Auditor scores 9.5 but identifies wrong governing equation | FAIL via critical-defect veto; targeted fix and re-audit. |
| User requests static code correctness only | Do not run excluded tests; report static evidence and limits. |
| Essential source unavailable after repeated retries | Report blocker and incomplete result, not certified success. |
| Final artifact path unavailable | Do not provide fabricated link; recover or report incomplete delivery. |
