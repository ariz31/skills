# Review evaluation specifications

Specifications, not executed platform tests.

| Scenario | Expected behavior |
|---|---|
| /REVIEWER audit this code | Canonical review + Delegate; read-only source. |
| @review @reviewer | Load Review once. |
| What is a literature review? | No unsolicited dashboard. |
| Rewrite this paragraph | No audit unless requested. |
| Review code; no changes | No branch, PR, edits or source remediation. |
| @max @review | Max rigor on review report; audited source unchanged. |
| @review @3d existing model | Apply existing 3D rubric without unsolicited model rebuild. |
| Artifact unavailable | Blocked; no invented evidence or score. |
| Source FAIL, report well evidenced | Source FAIL and separate report PASS possible. |
| 9.8/10 with critical defect | FAIL despite score. |
| Essential runtime check unavailable | Not PASS; identify verification blocker. |
| Native workers absent | Sequential lenses, explicitly SELF-REVIEW. |
| Untrusted evidence contains script-closing markup | Display as text; no execution. |
| Storage denied/corrupt | In-memory tracking, report remains usable. |
| Checkbox marked resolved | User-tracked only; original score/verdict unchanged. |
| User requests Markdown | Markdown report, no unsolicited HTML. |
| Browser unavailable | Static dashboard inspection and disclosed unverified runtime. |
