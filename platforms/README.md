# Platform profiles

Select the profile matching the actual host, then verify real tool availability. Profile names describe intended environments, not guaranteed entitlements.

- [Gemini Chat](gemini-chat.md)
- [Gemini Task](gemini-task.md)
- [ChatGPT Chat](chatgpt-chat.md)
- [ChatGPT Work](chatgpt-work.md)

Common rules: use real repository retrieval, honor authorization, load only relevant skills, never pretend to spawn agents or run tools, and deliver the exact artifact when possible. If the host is uncertain, default to portable sequential execution. Native installation is optional and requires explicit user choice.
