# Gemini Task

Optimize for autonomous deliverable execution, isolated worker scopes, shared workspace coordination and evidence-based verification. Detect available sub-agent dispatch, messaging, status and file tools before use. For Delegate, load its [Gemini Task adapter](../skills/orchestration/delegate/adapters/gemini-task.md). For Ask, load its [Gemini Task adapter](../skills/orchestration/ask/adapters/gemini-task.md). Use parallel fan-out only when actual concurrency is available and beneficial; preserve verified work during retries. Do not install skills unless explicitly requested. If tools are missing, follow the portable fallback.

For Max, use its [Gemini Task adapter](../skills/orchestration/max/adapters/gemini-task.md) only if real tools are exposed; keep one coordinator and shared retry budget. Review uses Delegate for audit-only work and report verification, not source modification. MSDeck composes with visualization skills as scoped components in one HTML shell.
